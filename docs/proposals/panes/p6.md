HANDOFF and R3 expect contract parity for methods the UI calls unconditionally (precedent: mock added `resumeAgents` / `broadcastRaw` specifically to avoid TypeError). **P0 should flag mock gap or UI guard.**

Home still comments “⌘⇧G” in places (`Home.jsx:365-366`, `AgentPane.jsx:501`) — documentation drift only; P0 §3 is right; do not reintroduce ⌘⇧G as the binding.
